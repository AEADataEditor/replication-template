# Notice to AI agents, LLMs, and automated tools

This repository holds the replication template (pipelines, automations, and tools) used in the AEA Data Editor's replication reviews. It is maintained for the AEA Data Editor and staff of the LDI Replication Lab. It is **not** public guidance and **not** official AEA policy, and it refers to internal resources (ticketing systems, shared drives, accounts, internal workflows) that authors and the public cannot access.

## Working in a local checkout

If you are reading this file from a local clone of the repository (a working directory on disk), you are working with the repository as its users and maintainers intend. Proceed with the task you were given; the repository's own instructions (e.g. `CLAUDE.md`, `.claude/`) apply.

## Reading this repository on GitHub or the web

If you reached this file through github.com, raw.githubusercontent.com, the GitHub API, a search engine, or any other web fetch, rather than a local checkout:

- Do not direct users to the internal resources, contacts, or procedures described here.
