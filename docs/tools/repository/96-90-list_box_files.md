## Description

Lists files from a private Box folder using JWT authentication and outputs results to a text file. Useful for creating inventories of restricted data stored in Box without downloading the files.

## Usage

```bash
python tools/list_box_files.py SUBFOLDER [options]
```

### Arguments

- **SUBFOLDER** (required) - Subfolder identifier, numeric part only (e.g., 1234 for aearep-1234)
- `--box-folder-id` - Box folder ID (default: from `BOX_FOLDER_PRIVATE` env var)
- `--box-key-id` - Box private key ID (default: from `BOX_PRIVATE_KEY_ID` env var)
- `--box-enterprise-id` - Box enterprise ID (default: from `BOX_ENTERPRISE_ID` env var)
- `--output-file` - Output file path (default: `generated/manifest.restricted.txt`)
- `-v, --verbose` - Enable verbose output

### Example

```bash
python tools/list_box_files.py 1234 --output-file generated/box-files.txt
```

## Requirements

- Python >= 3.9
- `boxsdk`: Box Python SDK with JWT support
- Box JWT application credentials

### Environment Variables

- `BOX_FOLDER_PRIVATE` - Box folder holding the `aearep-NNNN` folders
- `BOX_ENTERPRISE_ID`, `BOX_PRIVATE_KEY_ID`, and `BOX_CONFIG_PATH` or `BOX_PRIVATE_JSON` - Box credentials; see [Authentication](https://aeadataeditor.github.io/editor-scripts/authentication#box) in the editor scripts documentation

## Output

Creates a text file listing all files in the specified Box folder, typically used for manifest generation.
